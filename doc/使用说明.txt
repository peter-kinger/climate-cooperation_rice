RICE-N 文件调用与运行逻辑（当前 RLlib CPU 分支）

打开方法：
使用 draw.io / diagrams.net 的“文件 → 从设备打开”，选择 RICE-N-代码与运行逻辑.drawio。
文件包含四个页面，可在编辑器底部切换；所有框、文字、连接线均可编辑。
也可安装 VS Code 的 Draw.io Integration 扩展打开 .drawio 文件。

四个页面：
01 文件调用关系：入口、RLlib 适配层、核心模型、公式、参数与结果。
02 运行与结果流：训练、独立加载评估、绘图，附可运行命令。
03 谈判与步进：negotiation_on、stage、20/60 步与最低减排掩码。
04 活动模块与论文对应：按论文伪代码逐阶段定位实际函数与行号。

同名 SVG 与 PNG 为无需 draw.io 的预览，可用浏览器或图片查看器打开。
图例：蓝=代码，绿=数据，黄=执行阶段，紫=说明。实线表示调用 / 流程；虚线表示辅助输入。
图中路径均相对于项目根目录；行号对应本次梳理时的代码，后续代码修改可能导致行号变化。

重要说明：
本分支采用 RLlib 2.40 PPO；原版为旧版 A2C，不能视为原版训练结果的直接复现。
当前只实现一种基础双边谈判协议；negotiation_on 控制有 / 无谈判。
参数文件描述模型世界，策略训练调整网络参数，二者不同。
图片已对照实际代码，而非直接照抄论文图；论文和实现的差异列在第 04 页底部。
